# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-01
### Added
- Initial public release of CTF Assistant.
- Format detectors: Base64, Hex, Binary, Caesar cipher detection.
- Hash identification for MD5, SHA-1, SHA-256.
- Offline password cracking with mutation strategies.
- LLM client for local/cloud analysis of CTF challenges.
- CLI entrypoint and interactive workflow.
- Documentation: `README.md`, `CONTRIBUTING.md`, `LICENSE`.
